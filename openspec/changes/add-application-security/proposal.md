# Add Application Security

## Why

Операторам нужна отдельная страница, где можно смотреть инвентарь безопасности приложений, не выходя из shell. Частый сценарий — найти приложение и полистать список с длинными идентификаторами и данными о безопасности — становится полноценным разделом продукта.

## What Changes

В меню shell появляется пункт **Application Security**. Он открывает инвентарь с пагинацией на `/application-security`: записи о безопасности приложений, в том числе с такими длинными значениями, что вёрстка таблицы проходит реальную проверку.

## Почему именно эта задача

По бизнес-логике фича простая, но задевает все контракты, типичные для enterprise-фронтенда: discovery, роутинг, отдельно деплоящиеся UI и API, общий рантайм, lazy-загрузку, стоимость рендера и cleanup ресурсов.
