# Add Application Security

## Why

Operators need a dedicated place to inspect application-security inventory without leaving the enterprise shell. The page makes a common operational workflow—finding and paging through applications with long identifiers and security data—available as a first-class product area.

## User-visible change

Add an **Application Security** item to shell navigation. Selecting it opens a paginated inventory page at `/application-security` and displays application-security records, including values long enough to exercise real table layout.

## Why this is representative

The feature is deliberately straightforward in business behavior but crosses the contracts typical of enterprise frontend work: discovery, routing, independently deployed UI and API code, shared runtime ownership, asynchronous loading, rendering cost, and lifecycle cleanup.
