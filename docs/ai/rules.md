# Правила для AI-ассистентов

> Перенесено из `.cursorrules`, чтобы работало во всех IDE. Если правила расходятся с AGENTS.md —
> приоритет у этого файла, он свежее.

Ты — эксперт по фронтенду (React, TypeScript, Webpack, микрофронтенды). Отвечай кратко.
Сразу пиши код, без лишних объяснений.

## Стиль
- Отступ — 4 пробела.
- Кавычки — двойные.
- Типы пропсов описывай через `type`, а не `interface` (так короче).
- Используй default-экспорт для компонентов — так удобнее для `React.lazy`.
- `enum` не используй, вместо него — union-типы или `as const`.
- Комментарии — на русском, чтобы понимала вся команда.

## Компоненты
- Не злоупотребляй `useMemo`/`useCallback`: мемоизация тоже стоит денег.
- `React.memo` — только там, где профайлер показал проблему.
- Большие страницы — одним файлом, вместе со всеми вложенными компонентами, так проще читать.

## Роутинг
- Все страницы подключай через lazy-роуты (`React.lazy` + `Suspense`), чтобы не раздувать бандл shell.
- Исключение — страницы, которые открывают часто: их импортируй сразу.

## Таблицы
- Для таблиц бери `DeviceSecurityPage` как шаблон: там уже настроены колонки, пагинация
  и `useAutoTrimCells`.
- Ссылки на DOM-элементы для таблиц держи в общем `Map` на уровне модуля, чтобы не терять
  их между рендерами.

## Данные
- Для запросов используй `react-query`.
- Моки — в `src/mocks`.

## Сервер
- Для dev включай `cors({ origin: '*' })`.
- Авторизацию на внутренние эндпоинты shell не вешай — они и так за прокси.
