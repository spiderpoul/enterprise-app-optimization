# Демо-прогон: какой промпт откуда и в каком порядке

Два репозитория, в каждом свой агент: Run A (`demo-before`) и Run B (`demo/agent-ready-v2`).
Всё ниже делается в каждом репозитории одинаково. Тексты промптов — в [presentation/report-prompt.md](../../presentation/report-prompt.md):
нужны только разделы 2 и 3, остальное там справочное (чистый клон, сокрытие файлов, запуск замера руками) и
можно пропустить.

## Порядок

1. **Промпт 1 — задача.** Берёшь из `presentation/report-prompt.md`, раздел 2. Вставляешь в новую сессию агента.
   Один и тот же текст для A и B. Больше ничего агенту не говоришь.
2. **Ждёшь, пока агент закончит.** Сессию не закрываешь.
3. **Промпт 2 — отчёт и замер.** Берёшь из `presentation/report-prompt.md`, раздел 3. Вставляешь в ту же сессию.
   Агент сам сделает всё остальное:
   - перепишет `agent-report.md`: решения и откуда взял правило, что прочитал, проверки, сомнения;
   - запустит `node docs/demo/measure-run.cjs --append-report` (10–15 минут: сборка, приложение, браузер);
   - скрипт сам допишет в конец отчёта раздел 7 с цифрами. Чинить по результату агенту запрещено.
4. **Показываешь на докладе.** Один файл из каждого репозитория: `agent-report.md`.
   Раздел 1 — «он взял это правило отсюда», раздел 7 — цифры, снятые одним скриптом для обоих.

## Что где

| Что | Откуда | Кому |
|---|---|---|
| Промпт 1 (задача) | `presentation/report-prompt.md`, раздел 2 | A и B, одинаковый |
| Промпт 2 (отчёт и замер) | `presentation/report-prompt.md`, раздел 3 | A и B, одинаковый |
| Итог для демо | `agent-report.md` в корне репозитория | создают агент (разделы 1–6) и скрипт (раздел 7) |
| Полные метрики, скриншоты | `agent-metrics.md` и рядом | создаёт скрипт |

Если замер не отработал, запусти его сам в корне репозитория: `node docs/demo/measure-run.cjs --append-report`.
Приложение к этому моменту должно быть остановлено, а `npm ci` выполнен.

Если агент задаёт вопрос по ходу, ответ один для обоих: «Do not change shared code; this product's own
files are yours. Finish what you can and report what is left.»
