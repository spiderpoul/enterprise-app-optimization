# Как делать страницы

_Последнее обновление: март 2021_

## Общая схема

Приложение состоит из оболочки (shell) и набора микрофронтендов. Shell отвечает за layout,
меню, авторизацию и роутинг верхнего уровня. Часть страниц живёт прямо в shell
(`src/shell-app/client/pages`), часть — в микрофронтах (`src/microfrontends/*`).

```
┌──────────────────────── shell ────────────────────────┐
│  Header / Menu / Auth                                 │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐   │
│  │ shell pages  │ │ microfront A │ │ microfront B │   │
│  └──────────────┘ └──────────────┘ └──────────────┘   │
└───────────────────────────────────────────────────────┘
```

## Новая страница: рецепт

1. Возьми за шаблон `src/shell-app/client/pages/DeviceSecurityPage.tsx` — это эталонная страница
   с таблицей. Скопируй файл и переименуй.
2. Поменяй колонки и источник данных. Хук `useAutoTrimCells` оставь: он обрезает длинный текст
   в ячейках и уже отлажен.
3. Импортируй страницу в `MainLayout.tsx` статически, рядом с остальными:
   ```tsx
   import MyNewPage from '../pages/MyNewPage';
   ```
   Lazy-загрузку для страниц не используем: при первом переходе появляется мигание спиннера,
   а продукт на это жалуется.
4. Добавь пункт меню.
5. Запусти `npm run dev` и открой страницу.

## Производительность

Оптимизируй всё через `useMemo` и `useCallback`: колонки, обработчики, отфильтрованные данные,
даже простые строки. Так компоненты не перерисовываются лишний раз.

Вспомогательные компоненты (ячейки, бейджи, строки) удобно объявлять прямо внутри компонента
страницы: они видят все переменные из замыкания, и не нужно прокидывать пропсы.

Для работы с DOM-элементами таблицы (измерения, обрезка текста) храним их в `Map` на уровне
модуля — это быстрее, чем повторные `querySelectorAll`.

## Роутинг

Shell владеет роутингом верхнего уровня (`/reports`, `/users` и т. д.). Внутри своего префикса
микрофронт роутит сам через `react-router-dom`.

## API

Каждый микрофронт поднимает свой Express-сервер. Shell проксирует запросы `/api/mf/<name>/*`
на сервер микрофронта. Служебные эндпоинты shell (например, `/api/microfrontends/ack`)
открыты без авторизации — они нужны только внутренним сервисам.

## Инициализация shell

При старте shell загружает манифесты всех микрофронтов и только потом рендерит меню.
Если инициализация кажется медленной, ускорить её можно в `src/shell-app/client/main.tsx`.

## Стили

Стили изолируются через CSS-модули. Глобальные стили — только в shell.
