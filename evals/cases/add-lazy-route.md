# Добавить lazy-роут
Стартовый коммит: 186f075

## Задача            ← агенту отдаём только это
Добавь роут продукта, код которого загружается,
только когда пользователь на него заходит.

## Критерии          ← агент их не видит
- для роута собирается lazy-чанк с узнаваемым именем
- фичи нет в стартовом бандле shell; стартовые ассеты в пределах baseline
- страница действительно грузится через shell, навигация и ошибки работают
- проходят `npm run check:bundle`, `npm run lint` и `npm run build`

## Проверка
grader пока нет: оцениваем руками по критериям; `evals/graders/add-lazy-route.cjs`
пишем по первым оценённым промахам

## Откуда кейс
Открытый PR #53 оборачивает роуты продуктов в `React.lazy(() => import())`,
но корневой Babel-конфиг превращает `import()` в `require()`, и продукты
не собирают чанк; конфиг меняет только открытый PR #52.

## Классы ошибок (скрыты, для разбора упавших прогонов)
- Статический импорт фичи в стартовом дереве роутов.
- `import()` без чанка или чанк без узнаваемого имени.
- `lazy` в RouteObject, который `useRoutes` в shell никогда не вызывает.
- Чанк собирается, но недоступен через shell.
- Рост стартовых ассетов сверх допуска baseline.
