# Исправить утечку памяти
Стартовый коммит: 186f075

## Задача            ← агенту отдаём только это
Почини утечку detached DOM: пользователь листает страницу
продукта с пагинацией и уходит с неё, а DOM остаётся в памяти.

## Критерии          ← агент их не видит
- долгоживущий стейт приложения не держит detached DOM-узлы
- ресурсы и observer'ы освобождаются в cleanup при размонтировании
- репро остаётся регрессионным сценарием, который можно перезапускать
- проходят `npm run check:memory -- tests/memlab/<затронутый-роут>.scenario.js`,
  `npm run lint` и `npm run build`
