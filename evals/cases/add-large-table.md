# Добавить большую таблицу
Стартовый коммит: 186f075

## Задача            ← агенту отдаём только это
Добавь страницу инвентаря с пагинацией и реалистично
длинными значениями по текущей архитектуре фронтенда.

## Критерии          ← агент их не видит
- тяжёлая обработка данных не повторяется на посторонних ререндерах
- компоненты не перемонтируются без причины, состояние пагинации не разъезжается
- после навигации и пагинации не остаётся detached DOM-узлов
- страница грузится lazy-чанком; проходят `npm run check:bundle`,
  `npm run check:memory -- tests/memlab/<роут-инвентаря>.scenario.js`,
  `npm run lint` и `npm run build`

## Классы ошибок (скрыты, для разбора упавших прогонов)
- Синхронное преобразование всего набора данных на каждый рендер.
- Компоненты объявлены внутри рендера и перемонтируются.
- Долгоживущие коллекции держат ячейки таблицы после ухода со страницы.
- Код таблицы попал в стартовый бандл.
