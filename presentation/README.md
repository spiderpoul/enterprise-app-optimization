# Presentation

Презентация проекта на [Slidev](https://sli.dev/).

Требуется Node.js 22.12 или новее. Для `nvm` версия зафиксирована в `.nvmrc`.

## Запуск

```bash
nvm use
npm install
npm run dev
```

Slidev откроет презентацию в браузере. Исходник слайдов находится в
[`slides.md`](./slides.md).

## Другие команды

```bash
npm run build
npm run export
```
