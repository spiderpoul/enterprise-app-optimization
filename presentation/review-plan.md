# Переработка презентации по аудиту: статус

Аудит (2026-09-28) показал: у доклада есть сквозной пример, но нет сквозного развития событий. Середина шла по составу
harness (AGENTS.md → docs → спека → скиллы → субагенты → проверки → evals), каждый компонент проходил один и тот же цикл
«определение → хороший пример → плохой пример → показ файлов», а по заметкам доклад занимал 61 минуту при цели в 50.
Номера слайдов ниже — по текущему `slides.md`.

## Сделано

**Сквозная задача.** Весь основной поток построен вокруг страницы Application Security. Что нужно пользователю,
почему копирование соседней страницы кажется разумным и чем оно может обернуться, слушатель узнаёт до запуска
агентов (слайд 7). Главный вопрос доклада задан на слайде 4 вместо готового тезиса «дело не в модели».

**Новая макроструктура** — шесть частей, каждый компонент появляется после конкретного затруднения:

| Часть | Слайды | По заметкам |
|---|---|---|
| 1. Внутренняя модель есть, рабочую задачу ей не доверяем | 1–8 | 7:20 |
| 2. Агент находит рабочий пример и наследует старую ошибку (AGENTS.md, docs) | 9–12 | 6:10 |
| 3. Знания проекта не снимают неоднозначность задания (спека, границы) | 13–15 | 4:10 |
| 4. Код собрался, но задача ещё не решена (проверки, один скилл, лог, ревью) | 16–21 | 8:40 |
| 5. Смотрим, что получилось у двух запусков | 22–23 | 6:10 |
| 6. Повторится ли улучшение (один eval-кейс, первый шаг) | 24–28 | 5:00 |
| **Итого** | | **37:30** |

Было 56 слайдов основного потока и 61 минута; стало 28 слайдов и 37:30 по заметкам. Остаток до 50 минут —
на чат, переключения окон, ожидание агентов и вопросы.

**Сравнение Run A / Run B.**
- Промпт одинаковый для обоих: пользовательская задача без упоминания спеки. Спеку Run B агент находит по карте в AGENTS.md.
- Критерии оценки одинаковые (слайд 22). Фраза «заодно ускорить инициализацию shell» больше не попадает в Run A,
  поэтому правка чужого кода в любом прогоне — решение агента.
- Убрано противоречие «разница только в качестве спеки»: на слайде 8 прямо сказано, что одинаково, а что отличается,
  и что сравнение не показывает вклад отдельного файла.
- Run A больше не карикатура: перед стартом из него прячутся спека в спешке, зоопарк скиллов, «команда агентов»,
  второй файл правил и ревью-бот. Остаются общий AGENTS.md, документация 2021 года, `npm run check` и `check:ai`.
- Слайд 23 «Что этот запуск показывает, а что нет» заменил таблицу «что закрыло это в Run B».

**Убрано из основного потока:** рейтинг моделей, слайд «четыре причины», семь разделителей блоков, семь слайдов
«Что мы добавили / Переключаемся в репозиторий» (ссылки на коммиты-шаги теперь одной строкой на слайдах 11, 12, 14, 17, 26),
интерактив «куда положить», каталог скиллов, антипримеры AGENTS.md, документации, спеки, скилла, «команды агентов»
и eval, метрики pass@k, внедрение evals и связь скиллов с eval, финальный список из девяти пунктов.

**Объединено:** AGENTS.md — один слайд с тремя пометками (11) и таблица cross-zone вместе с историей реестра (15);
документация — один фрагмент с «Не копируй» (12); спека — «что тикет оставляет на усмотрение агента» (13) и фрагмент (14);
проверки — «сборка зелёная» (16), сообщение проверки (17) и live-цикл (18); evals — зачем (24), кейс (25), запуск (26).

**Запасные слайды (29–42):** модели и бенчмарки, условия Run A, SDD в legacy, уровни SDD и CodeSpeak, скиллы и владельцы,
когда нужен субагент, explorer, профильные ревьюеры, pass@k и pass^k, evals в команде, готовые скиллы.

**Точечные правки по аудиту:**
- Слайд 17: антипример теперь — короткое сообщение той же проверки, а не отсутствие проверки; в заметках сказано,
  что его написали для сравнения.
- Слайд 25: разведены явные требования и скрытые критерии. Lazy-загрузка в спеке — законное требование; в задаче eval
  её нет, потому что кейс меряет, доводит ли репозиторий агента до неё сам. Объяснено, почему в кейсе audit-log.
- Слайд 26: убраны «3 из 5 → 5 из 5 — сильный сигнал», «спор закрывается цифрой» и «для мёржа этого хватает»;
  цифры только собственные с репетиции.
- Слайд 19: объяснено, почему после AGENTS.md понадобился скилл: одна команда — строка в AGENTS.md, выбор из нескольких
  шагов — скилл.
- Финал (27–28): один посильный первый шаг и вывод из показанного результата вместо афоризма.
- Язык: убраны анонсы «Разберём…», «Посмотрим…», серия «Как не надо», лозунги «скрипт читает, модель думает»,
  «модель определяет потолок…»; исправлена фраза про челлендж на слайде 2; у каждого слайда в заметках есть «Переход».

**Сценарий live-показов** — `presentation/live-script.md`: условия сравнения, подготовка worktree, одинаковый промпт,
для каждого эпизода вопрос, окно, лимит времени и запасной вариант, список запасных артефактов, статус материала
(опыт / демо / иллюстрация) и тайминг.
