# Команда AI-агентов 🚀

Мы собрали полноценную виртуальную команду разработки! Каждый агент — эксперт в своей области,
и вместе они закрывают задачу от тикета до мержа без участия человека.

## Пайплайн

```
Задача → PM → Архитектор → Разработчик → QA → PR ✅
```

1. **PM** (`pm.md`) читает задачу и превращает её в понятное описание для архитектора.
2. **Архитектор** (`architect.md`) продумывает решение и передаёт разработчику техническое задание.
3. **Разработчик** (`developer.md`) пишет код по ТЗ архитектора.
4. **QA** (`qa.md`) проверяет результат и одобряет PR.

## Почему это круто
- Как в настоящей команде: разделение ответственности.
- Каждый агент фокусируется на своём и не отвлекается.
- Все агенты имеют полный доступ к репозиторию, поэтому никто никого не ждёт.
- Можно запускать ночью — утром готовый PR.

## Как запустить
Передай задачу агенту `pm` — дальше всё произойдёт само.
