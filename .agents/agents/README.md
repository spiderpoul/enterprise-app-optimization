# Субагенты

Каждый файл здесь описывает субагента, которого основной агент вызывает как функцию: узкий вход,
description, который говорит, когда его звать, разрешённые инструменты и фиксированная форма ответа
с лимитом строк и доказательствами file:line. Все субагенты по инструкции только читают — `explorer` исследует,
`log-analyst` читает длинный вывод, `reviewer` смотрит на готовый diff свежим контекстом. Код меняет
только основной агент.

«Только чтение» в тексте — инструкция модели. Технически её подкрепляют права конкретного CLI: в
OpenCode-адаптерах `edit: deny` и список разрешённых команд Bash. Это ограничения клиента, а не
изоляция: другие инструменты, MCP-серверы и настройки окружения они не закрывают. Проверяй права в своём CLI.

## Как субагент попадает в работу
1. **Автоматически, по description.** Агент видит description всех субагентов и сам решает позвать
   того, чья задача подходит: «как это сделано сейчас и кто зависит» → `explorer`, длинный лог → `log-analyst`.
   Поэтому description пишем как условие вызова, а не как рекламу.
2. **Из шага скилла или спеки.** Процедура прямо называет субагента: шаг 2 в
   `openspec/changes/add-application-security/tasks.md` («Изучи один текущий микрофронт», сейчас шаг 2),
   шаг 2 скилла `safe-change`, шаг 2 скилла `story-analysis` → `explorer`; «Отдай свой diff субагенту
   `reviewer`» в tasks.md (сейчас шаг 10) → `reviewer`.
3. **Явно, по имени.** Человек пишет в промпте «попроси explorer…» или упоминает его через `@explorer`.

## Синтаксис
Синтаксис frontmatter отличается между агентными CLI: названия полей, способ перечислить инструменты,
каталог, который CLI читает. Каноничные описания лежат здесь, в `.agents/agents/`. OpenCode читает
только `.opencode/agents/`, поэтому рядом лежат адаптеры с тем же телом и его синтаксисом прав
(`mode: subagent`, `permission: { edit: deny, bash: {...} }`): `.opencode/agents/explorer.md`,
`reviewer.md`, `log-analyst.md`. Тело адаптера совпадает с каноничным, отличается только frontmatter.
Меняешь тело субагента — меняй оба файла в одном MR. Для другого CLI сделай такой же адаптер или
симлинк там, где он ищет агентов.
