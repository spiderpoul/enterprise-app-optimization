# Разбор задачи до кода

1. Перескажи задачу в одном абзаце: кто пользователь, что он увидит, зачем.
2. Найди, что заденет изменение: таблица «Что ещё заденешь» в AGENTS.md и раздел
   «Подводные камни» нужной документации. Для поиска по коду — субагент explorer.
3. Выпиши вопросы, без ответа на которые нельзя начинать (данные, права, пустые
   состояния, ошибки, что вне scope). Не придумывай ответы — остановись и спроси.
4. Когда вопросы закрыты, создай openspec/changes/<id>/ по образцу
   add-application-security: публичный контракт, сценарии WHEN/THEN, вне scope, Готово.
5. Результат: черновик спеки и список решений для владельца из CODEOWNERS. Код не пиши.
