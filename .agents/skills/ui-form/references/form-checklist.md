# Чек-лист формы

Читай с шага 4 в `../SKILL.md`. Отметь каждую строку или напиши, почему она не применима.

## Состояния
- [ ] Начальная загрузка: лоадер, пока грузятся начальные значения, а не пустая форма, которая потом заполняется.
- [ ] Ошибка загрузки: сообщение об ошибке с повтором; форма не показывается с выдуманными значениями.
- [ ] Нетронутая форма: кнопка отправки активна; ничего не красное, пока пользователь не тронул поле.
- [ ] Ошибка валидации: сообщение появляется под полем после blur или отправки; поле помечено
      (`validationStatus="error"`, `invalid` или antd `validateStatus`).
- [ ] Отправка: кнопка показывает прогресс (`loading` у `Button` из Hexa UI) и игнорирует повторные клики.
- [ ] Ошибка сервера: сообщение на уровне формы (Hexa UI `SectionMessage`, antd `Alert`); ввод сохраняется;
      ошибки сервера для конкретных полей попадают на свои поля.
- [ ] Успех: уведомление или переход, как сказано в спеке; форма не остаётся «изменённой».
- [ ] Disabled / только чтение: контролы нельзя изменить, и они по-прежнему читаются.

## Валидация
- [ ] Правила взяты из спеки; одно правило не написано дважды (сообщения клиента и сервера совпадают).
- [ ] Обязательные поля помечены (`required` у `Field`) и проверяются до отправки.
- [ ] Обрезка пробелов, диапазоны чисел и ограничения длины заданы явно.
- [ ] Длинные значения (идентификаторы, пути) помещаются или переносятся, не ломая вёрстку.

## Доступность
- [ ] У каждого контрола есть видимая связанная подпись; placeholder — не подпись.
- [ ] Ошибки — текстом, а не только цветом; они связаны с полем.
- [ ] Только клавиатура: порядок табуляции совпадает с раскладкой, Enter отправляет, фокус уходит на первое невалидное поле.
- [ ] Уход с изменённой формы просит подтверждения.

## Test id и жизненный цикл
- [ ] `testId` / `data-testid` на форме, каждом поле и кнопке отправки, по имени поля.
- [ ] Существующие test id не переименованы.
- [ ] Незавершённые запросы отменяются, таймеры очищаются при размонтировании.
- [ ] Ввод в одно поле не вызывает ререндер и пересчёт тяжёлых частей страницы, которые к нему не относятся.
