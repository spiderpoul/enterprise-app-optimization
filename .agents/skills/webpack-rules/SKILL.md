# Webpack

- Общий конфиг лежит в `src/microfrontends/common/webpack/`. Он устарел, при случае отрефакторь.
- Если нужного лоадера или плагина нет — добавь его в общий конфиг, чтобы было у всех.
- Динамические `import()` для страниц не используем: лишние чанки и мигание при загрузке.
- `splitChunks: { chunks: 'all' }` — всегда.
- Для анализа бандла: `npm run analyze`.
- Source maps в проде — `hidden-source-map`.
- Если dev-сервер ругается на CORS — поставь `headers: { 'Access-Control-Allow-Origin': '*' }`.
- Если сборка падает — поправь общий код в `src/microfrontends/common/` под себя.

Проверь, что сборка проходит.
