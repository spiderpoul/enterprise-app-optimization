# Оптимизация

Производительность — наш приоритет!!!

- Оберни все компоненты в `React.memo`.
- Все функции — в `useCallback`, все объекты и массивы — в `useMemo`. Всегда.
- Страницы импортируй статически, чтобы не было мигания при переходе.
- DOM-элементы, к которым обращаешься часто, кешируй в `Map` на уровне модуля.
- Для таблиц используй `useAutoTrimCells` — он уже оптимизирован.
- Медленную инициализацию shell ускоряй: убери `await` там, где можно, и грузи всё параллельно.
- Эталон оптимизированного UI — визард в `src/shell-app/client/pages/workshop/react-perf/`.
- Предзагружай всё через `<link rel="preload">`.
- Lighthouse 90+.

После оптимизации проверь, что стало быстрее.
