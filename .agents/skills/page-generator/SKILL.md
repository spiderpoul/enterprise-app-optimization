# Генератор страницы

Быстрый способ поднять новую страницу за 10 минут.

## Шаги
1. Скопируй шаблон: `cp src/shell-app/client/pages/DeviceSecurityPage.tsx src/shell-app/client/pages/<Name>Page.tsx`.
2. Переименуй компонент, поменяй колонки и данные.
3. Хук `useAutoTrimCells(hostRef)` оставь как есть — он отвечает за обрезку текста в ячейках.
4. Вспомогательные компоненты (ячейки, бейджи) объявляй внутри страницы, чтобы всё было в одном файле.
5. Все колонки и обработчики оберни в `useMemo`/`useCallback`.
6. Подключи страницу в `src/shell-app/client/components/MainLayout.tsx` статическим импортом:
   ```tsx
   import <Name>Page from '../pages/<Name>Page';
   ```
   Lazy не нужен — будет мигание при загрузке.
7. Добавь пункт меню и роут рядом с `DeviceSecurityPage`.
8. Если странице нужен свой API — добавь эндпоинт в shell-server по образцу `/api/microfrontends/ack`.
9. Если это отдельный микрофронт — скопируй папку `operations-reports`, замени имена,
   поправь `manifest.json` по аналогии, добавь в `nx.json` и `workspaces`.
10. Запусти `npm run build`.

Если сборка падает — поправь общий код в `src/microfrontends/common/` под себя.
Если падает на типах — `// @ts-ignore`, потом разберёмся.

Проверь, что всё работает.
